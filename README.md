Current stabilization wave: 2026-08-19. **Grid Write** makes the matra grid a direct notation editor: each box writes one matra into the same Markdown source and updates the score and playback immediately, while invalid drafts remain isolated from the composition. Clicking a rendered score matra centers its exact editor cell, and switching between Text Write and Grid Write retains the current line/matra. **Beginning** provides an intentional return to the first line, while **Writing focus** creates a larger split writing surface. Right-clicking a matra (or pressing Shift–F10) opens its compact musical menu: choose an exact note attack for da/ra/diri/chikari, start and finish a `(phrase)xN`, toggle `||: … :||`, place or remove the `|1` alternate-ending boundary, or turn the cell into a hold/rest. Diri now has two explicit choices: **same note** schedules two strokes on one pitch, while **next note** binds two successive written pitches as one spoken di-ri; the editable source forms are `diri` and `di-ri`. The latter renders and prints as one continuous V aligned to both attacks, including across a matra boundary, and cannot be split between printed systems. Written rhythmic gaps are also bol targets: `^da` places chikari in the empty subdivision and da on the following note, while Grid Write gives that gap its own `+` chikari control. During playback, both gap and note-attached chikari add a brief, softer upper Sa pluck without replacing the melody note. The existing bol menus and visible ending controls remain available, and **Copy bols** copies a line's editable bol lanes. Exact score anchoring prevents edits and deletions from pushing the working music down. Compact alternate endings use `|1` plus the following notation line: the shared phrase prints once, then real **1st time** and **2nd time** matra grids branch at the exact divergence and remain together when systems wrap. Grid Write can add, move, or remove this boundary visually while keeping `|1` as the interchangeable Markdown form. Clean, Matra cells, and Graph Paper share this layout. The score and editor retain persistent **Cells** and **Paper** appearances, with real matra cells rather than a background overlay; PDF export offers the same surface. Graph Paper plans line breaks by actual matra and structural cells, so dense beats no longer collapse into half a row, while descriptions and numbered cues occupy compact strips between full-height music rows. **Library**, **Linked phrases**, and **Queue** are now distinct surfaces; the session Queue supports add-without-interrupting, reorder, remove, clear, next/previous, repeat track/queue, stable archive IDs, explicit local-source reconnection, and the approved A–B exit policy.
